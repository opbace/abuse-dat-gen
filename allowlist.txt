# Domains that must never be blocked, whatever upstream lists say.
#
# An entry protects the name and everything below it: "google.com" also
# protects "mail.google.com". A rule removed because of this file is listed
# under "removed_by_allowlist" in manifest.json, so every exception is visible.
#
# Only add a domain operated by the organisation itself. Never add a service
# that hosts other people's content (githubusercontent.com, amazonaws.com,
# googleusercontent.com, pages.dev, t.me, ...): abuse lives on those, and
# shared-hosting suffixes are already protected from whole-suffix rules by the
# Public Suffix List check.
#
# False positive in an upstream list? Report it upstream first:
#   HaGeZi: https://github.com/hagezi/dns-blocklists/issues
